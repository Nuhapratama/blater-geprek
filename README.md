📌 Latar Belakang dan Tujuan

Blater Geprek merupakan konsep usaha kuliner yang menyediakan berbagai pilihan menu ayam geprek dan minuman.

Project ini bertujuan membuat website sederhana yang dapat membantu calon pelanggan mengenal usaha, melihat pilihan menu, dan menghubungi penjual melalui WhatsApp.

Website ini merupakan website statis yang dibuat untuk kebutuhan project Catalyst.

✨ Fitur dan Section Website

1. Home — Menampilkan halaman utama dan informasi singkat Blater Geprek.
2. About Us — Menampilkan profil dan deskripsi usaha.
3. Our Menu — Menampilkan katalog menu makanan dan minuman.
4. Filter Menu — Membantu pengunjung melihat menu berdasarkan kategori.
5. WhatsApp Ordering — Mengarahkan pelanggan ke WhatsApp untuk menghubungi penjual.
6. Responsive Navigation — Memudahkan navigasi pada perangkat desktop maupun mobile.
7. Contact — Menampilkan informasi kontak usaha.

🛠️ Teknologi yang Digunakan

* HTML — Membuat struktur halaman website.
* CSS — Mengatur desain, warna, tata letak, dan tampilan responsif.
* JavaScript — Menambahkan interaksi dan fungsi pada website.
* Git dan GitHub — Mengelola versi kode dan kolaborasi kelompok.

🚀 Cara Menjalankan Website Secara Lokal

1. Clone repository:

git clone https://github.com/Nuhapratama/blater-geprek.git

2. Masuk ke folder project:

cd blater-geprek

3. Buka file index.html menggunakan browser.

Website dapat dijalankan secara lokal tanpa backend atau database.
